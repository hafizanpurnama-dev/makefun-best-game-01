## 🎮 Gameplay

- **Controls:** Arrow keys / WASD to move, Space / Z / J to shoot, or use mouse/touch
- **Enemies:** Scouts, Fighters, Tanks, Speeders — each with unique behavior
- **Bosses:** Every 3 waves — massive bullet-hell encounters
- **Power-ups:** Rapid Fire ⚡, Spread Shot 🔱, Shield 🛡
- **Waves:** Escalating difficulty — how far can you go?

## 🏗️ Tech

- **HTML5 Canvas** — hardware-accelerated 2D rendering
- **Web Audio API** — procedural sound effects
- **Vanilla JS** — zero dependencies, single-file

## 🚀 Quick Start

### Open directly

Just open `index.html` in your browser.

### With server

```bash
node --experimental-strip-types main.ts
# → http://localhost:3000
```

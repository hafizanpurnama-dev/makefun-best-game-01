A fast-paced arcade space shooter built for make.fun best-game-01. Dodge enemy waves, blast through neon-lit battles, and climb the leaderboard.

## Features

- Neon-drenched visual style with particle explosions
- 3 enemy types (Drone, Fighter, Tank) with distinct behaviors
- Progressive difficulty — each wave adds more enemies
- Power-up system
- Web Audio synthesized sound effects (no external files)
- Title screen, HUD overlay, and game over screen
- Keyboard controls: Arrow keys / WASD + Space

## How to Play

```bash
node serve.ts
# Open http://localhost:8080
```
